# Numpy
This repository contains my learning and practice work on NumPy, the fundamental Python library for numerical computing. It includes examples, exercises, and notes covering arrays, indexing, slicing, mathematical operations, and basic linear algebra concepts, serving as a foundation for Data Science, AI, and Machine Learning.

### 🔹 Topics Covered
- NumPy arrays and data types
- Array creation methods
- Indexing and slicing
- Mathematical and statistical operations
- Broadcasting
- Basic linear algebra
- Practical examples and exercises
